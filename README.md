# SJA-UTA - APE 3

Proyecto de Estructura de Datos de Ingenieria de Software de la Universidad Tecnica de Ambato.

El Sistema Jerarquico Academico utiliza dos estructuras:

- Un arbol general para representar la organizacion academica: universidad, facultades, carreras, niveles y paralelos.
- Un arbol binario de busqueda para gestionar los estudiantes de cada paralelo, ordenados por matricula.

## Organizacion del repositorio

| Carpeta                    | Contenido                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- |
| [Grupo1](Grupo1/README.md) | Fase 1: caso practico, modelos, enumerados, diagramas, datos de prueba y codigo base.                         |
| [Grupo2](Grupo2/README.md) | Insercion, busqueda, recorridos recursivos, trazas, modificacion y eliminacion del ABB, reto y documentacion. |

## Ejecucion

Consultar las instrucciones del README de cada grupo.

Los proyectos se compilan por separado, porque contienen clases con los mismos nombres y paquetes. No compilar juntos los archivos Java de Grupo1 y Grupo2.
